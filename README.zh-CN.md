# StashBar

[English](README.md) | [简体中文](README.zh-CN.md)

给刘海屏 MacBook 用的菜单栏"抽屉"小工具——把不常点、但要一直运行的菜单栏图标先收起来，
需要用的时候再点开。

就像我的世界里的箱子：扔进去的东西还在运行，只是暂时看不见，打开箱子就能拿。

![截图：关闭状态](docs/closed.png)
![截图：打开状态](docs/open.png)

## 问题

带刘海的 MacBook（14/16 寸 MacBook Pro）菜单栏可用宽度很窄。只在菜单栏常驻图标的
App（Cloudflare WARP、Dropbox、VPN 客户端、剪贴板管理器……）很容易被刘海挡住或挤出
屏幕之外。常见的解决办法是先退出这个 App 腾地方，用的时候再重新打开——很烦。

## StashBar 做什么

StashBar 在菜单栏加一个小抽屉图标（🗃）。它左边的一段区域就是"暂存区"：按住 ⌘
把任意菜单栏图标拖到这段区域里（和系统自带的菜单栏图标排序手势一样），StashBar 会
用一块和菜单栏本身材质一致的遮罩盖住它——图标和它背后的 App 都还在运行，只是暂时
被盖住看不见。

- **点一下抽屉** → 遮罩收起，暂存区里所有图标恢复原位、可以正常点击。
- **点你需要的图标**（比如打开 Cloudflare WARP 菜单）→ 抽屉自动关闭，重新盖上。
- **右键抽屉图标** → 调整暂存区宽度、自动关闭时间、开机自启动。

不会删除任何图标，不会杀掉任何进程——这只是对菜单栏一段区域做纯视觉上的
显示/隐藏切换。

## 安装

需要 macOS 13 及以上，以及 Xcode 命令行工具（PATH 里要有 `swift`）。

```bash
git clone https://github.com/zhuhroscar-tech/stashbar.git
cd stashbar
./build_app.sh
```

这会编译 release 版本、打包成 `StashBar.app`、做 ad-hoc 签名、安装到
`/Applications/StashBar.app` 并启动它。菜单栏图标会立刻出现。

因为没有做 Apple 公证，从 Finder 直接双击首次打开可能会提示"无法验证开发者"——按
上面的方式从终端运行 `./build_app.sh` 就不会触发同样的拦截；如果还是被拦，在 Finder
里右键这个 App → 打开，允许一次即可。

## 使用方法

1. 按住 **⌘** 把某个菜单栏图标拖到 🗃 抽屉图标的**左边**。
2. 它就被收起来了——看不见，但背后的 App 仍在运行。
3. **点击** 🗃 打开抽屉，正常使用那个图标。
4. 抽屉会自动重新盖上（默认 6 秒，可调），点别的地方也会立刻关闭。

右键 🗃 可以设置：
- **加宽 / 缩窄暂存区** —— 抽屉遮住的菜单栏宽度。
- **自动关闭时间** —— 4 秒 / 6 秒 / 10 秒 / 20 秒 / 关闭。
- **开机自启动**。

## 原理

StashBar 由一个 `NSStatusItem` 加一个无边框的 `NSVisualEffectView` 窗口组成，窗口层级
比系统状态栏高一级（`.statusBar + 1`），高度和材质都与真实菜单栏一致。关闭抽屉时显示
这个遮罩窗口盖住暂存区；打开抽屉时调用 `orderOut` 让下面的真实图标重新可见、可点击。
它永远不拦截点击事件（`ignoresMouseEvents = true`）——纯粹是视觉遮罩，不会改变被
暂存的 App 的任何行为。

不需要辅助功能权限，不使用私有 API，也不会移动或重命名其他 App 的状态栏图标：它只
决定菜单栏某一段区域此刻是否被绘制遮罩，仅此而已。
